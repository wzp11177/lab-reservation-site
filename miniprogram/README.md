# 实验室预约微信小程序

这是网页预约系统的原生微信小程序版本，和网页共用同一个 Supabase 数据库。

## 打开项目

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`miniprogram`。
4. 如果只是本地预览，可以先使用测试号；如果要上传发布，需要把 `project.config.json` 里的 `appid` 改成你的小程序 AppID。

## 请求域名

小程序正式预览、真机调试和发布前，需要在微信公众平台配置服务器域名：

1. 打开微信公众平台的小程序后台。
2. 进入“开发管理” > “开发设置”。
3. 在“服务器域名”里添加 request 合法域名：

```text
https://nhjzugsqiqrfubyvichj.supabase.co
```

开发者工具里临时调试时，也可以在“详情”里勾选“不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书”，但正式上线必须配置合法域名。

## 发布

1. 在微信开发者工具里预览并确认预约/取消正常。
2. 点击“上传”。
3. 到微信公众平台提交审核。
4. 审核通过后发布。
